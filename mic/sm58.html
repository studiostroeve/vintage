VINTAGE MICROPHONES

Anbernic RG35XX+

A beautiful handheld!

  • Display
    • 3.5″ IPS screen with full viewing angles (OCA laminated)
    • Resolution: 640×480 (4:3 aspect ratio)
  • Processor & Graphics
    • CPU: Allwinner H700 — Quad-core ARM Cortex-A53 (~1.5 GHz)
    • GPU: Mali-G31 MP2
  • Memory & Storage
    • RAM: 1 GB LPDDR4
    • Storage: 64 GB microSD (expandable, dual microSD slots supported)
  • Connectivity & Ports
    • USB-C for charging
    • Mini-HDMI output to TV or monitor
    • Wi-Fi (and Bluetooth on some versions)
    • Headphone jack
  • Battery & Power
    • Battery capacity: ~3300 mAh
    • Charging: 5 V / 1.5 A via USB-C
    • Estimated playtime: 6–8 hours
  • Physical Specifications
    • Dimensions: ~117 mm × 81 mm × 20 mm
    • Weight: ~165 g
    • Vertical Game Boy-style layout with D-pad, ABXY, and shoulder triggers
    • Available in multiple colors (e.g., gray, transparent, black)
  • Software & Emulation
    • Runs Linux-based OS (stock firmware supports many retro systems)
    • Supports community OSes like Garlic OS and ArkOS
    • Plays systems up to PS1, N64, GBA, SNES, NES, Game Boy, and some PSP
    • 4:3 screen ideal for classic retro consoles
  • Pros
    • Excellent value for its price
    • Bright, crisp display for retro games
    • Compact and portable
    • Strong emulation performance for 2D systems
  • Cons
    • No analog sticks (limits 3D games)
    • Triggers can feel slightly loose
    • Stock software and updates are basic
    • Limited 3D system performance (e.g., demanding PSP titles)
  • Price & Ratings
    • Approx. €85.95
    • Average rating: 4.7 / 5 (based on ~1800 reviews)
